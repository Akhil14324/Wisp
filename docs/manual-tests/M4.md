# M4 Scheduler and routines: manual checklist

Covers FR-SCH-01 to 10.

| # | Step | Expected | Pass |
|---|---|---|---|
| 1 | Command mode: "Every morning at 9, open Unity and Spotify". | A card says it is scheduled. Routines lists a daily 09:00 routine with the command "Open Unity and Spotify". | [ ] |
| 2 | Command mode: "Search Amazon for gift wraps on 10th November at 11:00". | A one-time job for 10 Nov 11:00 appears. | [ ] |
| 3 | Routines > New routine: once, two minutes from now, command "open notepad". | At the due time (within 5 s) Notepad opens and a notification shows the summary. Run history shows "ok" with a duration. | [ ] |
| 4 | Create a daily routine due in 2 minutes; quit Wisp from the tray; wait 20 minutes; start Wisp. | Run history records "missed" and a notification says so. | [ ] |
| 5 | Same as 4 but restart Wisp 5 minutes after the due time. | The job runs right away (within the 15 min grace window). | [ ] |
| 6 | Create a routine due in 2 minutes; lock the PC (Win+L) before it is due; unlock 3 minutes later. | It runs right after you unlock. | [ ] |
| 7 | Repeat 6 but stay locked 20 minutes. | Recorded as missed. | [ ] |
| 8 | Create a routine "open notepad and type hello" without Allow Computer Use. Run now. | The run does not use Computer Use. | [ ] |
| 9 | Ask by voice to allow Computer Use on a routine. | Not possible: the checkbox is only in the main window. | [ ] |
| 10 | Tick Allow Computer Use on a routine whose command needs it; Run now while away from the PC. | It pauses on any confirmation and notifies; with no answer for 10 minutes it is recorded as "aborted". | [ ] |
| 11 | Click Run now on six routines quickly. | One runs at a time; the sixth is rejected because the queue is full. | [ ] |
| 12 | Disable, edit and delete routines. | Each works; a disabled routine does not run. | [ ] |
| 13 | Advanced (cron) with `*/5 * * * *`. | Runs every 5 minutes. | [ ] |
