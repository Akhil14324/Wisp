# M7 Hardening: manual checklist

Covers NFR-01 to 34. Record measured numbers in `docs/PERFORMANCE.md`.

| # | Step | Expected | Pass |
|---|---|---|---|
| 1 | NFR-01: set `WISP_LOG=debug`, hold Ctrl+Win 20 times; compare chord and recording-start timestamps in the log. | 150 ms or less. | [ ] |
| 2 | NFR-02: time 10 dictations of ~10 s from release to text. | 4 s or less at p90. | [ ] |
| 3 | NFR-03: time 10 Circle to Ask answers from release to card text. | 6 s or less at p90. | [ ] |
| 4 | NFR-05: Task Manager > Details with the island collapsed and idle for 5 min. Add Wisp plus its `msedgewebview2.exe` children. | Under 1% CPU and under 200 MB RAM. | [ ] |
| 5 | NFR-06: reboot; time from sign-in to the first working Ctrl+Win. | 3 s or less after the Wisp process starts. | [ ] |
| 6 | NFR-07: three routines due at the same minute. | Each starts within 5 s of due (queue order). | [ ] |
| 7 | NFR-08/FR-CU-10: Esc x3 during a task. | All activity ends within 1 s. | [ ] |
| 8 | NFR-30: rename a model to a bogus id in Settings > Models; give a command. | "Model not available. Check Models in Settings"; no crash. | [ ] |
| 9 | NFR-31: end Wisp from Task Manager while a Computer Use step holds a key (hard to time; try during typing). | No stuck keys afterwards. | [ ] |
| 10 | NFR-32: sleep the PC, wake it, use Ctrl+Win right away. | Hotkeys work; the log shows "keyboard hook reinstalled". | [ ] |
| 11 | NFR-33: no network. | Gemini features show "No connection to Gemini" within 30 s; to-do and island panels keep working. | [ ] |
| 12 | NFR-34: quit Wisp, overwrite `%APPDATA%\Wisp\wisp.db` with junk text, start Wisp. | A notice says the data was reset; the old file is kept as `wisp.db.corrupt-<time>`. | [ ] |
| 13 | NFR-22: Settings > Privacy > Delete all data (key kept). | To-dos, routines, history, presets and logs are gone; the key still works. | [ ] |
| 14 | Settings > About > Copy diagnostics, paste it. | Version, Windows build, model ids, counters; no content or key. | [ ] |
| 15 | 2-hour soak: use a hotkey every few minutes while working normally. | No hook loss (chords always work); memory grows less than 50 MB. | [ ] |
| 16 | NFR-14: Resource Monitor > Network while using every feature. | Only `generativelanguage.googleapis.com` (plus pages you asked to open in your browser). | [ ] |
