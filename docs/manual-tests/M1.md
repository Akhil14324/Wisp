# M1 Hotkeys and dictation: manual checklist

Covers FR-HK-01 to 05, FR-DIC-01 to 09, FR-GEM-01 to 07.

| # | Step | Expected | Pass |
|---|---|---|---|
| 1 | Open Notepad. Hold Ctrl+Win, say "Hello, this is a test of Wisp dictation", release. | The island shows a waveform while held. Clean, punctuated text appears in Notepad within 4 s of release. | [ ] |
| 2 | Repeat 10 times with ~10 s sentences and time each one. | At least 9 of 10 insert within 4 s (p90). | [ ] |
| 3 | Dictate: "uh so meet at nine... no, ten?" | The inserted text has "10" or "ten" and not "nine". | [ ] |
| 4 | After any Ctrl+Win dictation, check the Start menu. | The Start menu never opens. | [ ] |
| 5 | Press Ctrl+Win+D quickly (new virtual desktop), then Ctrl+Win+F4 to close it. | Windows handles both shortcuts normally; Wisp does not start listening. | [ ] |
| 6 | Tap Ctrl+Win for a moment (under 300 ms). | Nothing is inserted and no error is shown. | [ ] |
| 7 | Hold Ctrl+Win and stay silent for 3 s. | "Didn't catch that" on the island for about 2 s; nothing inserted. | [ ] |
| 8 | Copy some text, dictate into Notepad, then paste with Ctrl+V. | The dictation was inserted, and your original clipboard text is back on the clipboard. | [ ] |
| 9 | Copy an image (e.g. Print Screen), then dictate into Notepad. | The text is typed (slightly slower); afterwards the image is still on the clipboard. | [ ] |
| 10 | Run Notepad as administrator and dictate into it. | Nothing is typed; a notification says Windows blocks input into admin apps and the text is on your clipboard. | [ ] |
| 11 | Settings > Audio: add "Akhil" to the dictionary; dictate a sentence with that name. | The name is spelled "Akhil". | [ ] |
| 12 | History page. | The last dictations appear with Copy buttons; Copy puts the text on the clipboard. | [ ] |
| 13 | Turn "Keep dictation history" off. | The list empties and new dictations are not stored. Turn it back on. | [ ] |
| 14 | Unplug a USB microphone while holding Ctrl+Win. | The island shows "The microphone was disconnected"; nothing is stuck; the next dictation (with the mic back) works. | [ ] |
| 15 | Disconnect from the network and dictate. | "No connection to Gemini" within the timeout. | [ ] |
| 16 | Hold Ctrl+Win and talk for over 2 minutes. | Recording stops by itself at 120 s and the text is inserted. | [ ] |
| 17 | Open Task Manager, end task on nothing; instead stress the PC (e.g. a big compile) and keep using hotkeys for 5 min. | Hotkeys keep working. If the log shows "hook looks removed; reinstalling", chords recover within 2 s. | [ ] |
| 18 | Check `%LOCALAPPDATA%\Wisp\logs\wisp.*.log`. | Only events, codes and timings; no transcript, audio or key. | [ ] |
