# M2 Voice commands: manual checklist

Covers FR-CMD-01 to 09. Use the default "Full" Loadout unless a step says otherwise.

| # | Step | Expected | Pass |
|---|---|---|---|
| 1 | Hold Ctrl+Alt+Space, say "Open Spotify", release. | The island shows Listening, then Thinking; Spotify launches; a short result shows for up to 6 s. | [ ] |
| 2 | "Search how to cook spaghetti on YouTube". | The YouTube results page for that query opens in your default browser within 4 s. | [ ] |
| 3 | "Search Amazon for gift wraps". | `amazon.in` search results open. | [ ] |
| 4 | "Set volume to 30". | Speaker volume becomes 30%. | [ ] |
| 5 | Play music in Spotify or YouTube, then "Pause the music". | Playback pauses. "Next track" skips. | [ ] |
| 6 | Hold Ctrl+Alt+Space in Notepad. | No space character is typed into Notepad. | [ ] |
| 7 | "Open Unity" with both Unity Hub and a Unity editor installed. | Up to 3 chips appear on the island; clicking one launches it. | [ ] |
| 8 | "Open Photoshop" (not installed), then ask again. | The error is reported and the loop stops after 2 failed tool calls; the island shows the error. | [ ] |
| 9 | "Lock my computer" or "press Win+L". | Wisp refuses: Win+L is blocked. | [ ] |
| 10 | "Copy 'hello there' to the clipboard", then paste somewhere. | "hello there" is pasted. | [ ] |
| 11 | "Set my wallpaper to C:\Windows\Web\Wallpaper\Windows\img0.jpg". | The wallpaper changes. | [ ] |
| 12 | Click the island pill, type "open notepad", press Enter. | Notepad opens (typed fallback, FR-CMD-04). Focus returns to the window you were in. | [ ] |
| 13 | Customize > Loadout: switch to Minimal, then say "set volume to 50". | The model has no volume tool; it answers without changing the volume. Switch back to Full. | [ ] |
| 14 | History page. | Each command lists tools called with arguments, outcome and duration; expand one to see details. | [ ] |
| 15 | Turn off the network, give a command. | "No connection to Gemini" within the timeout. Typed app launch through the island still fails gracefully (needs Gemini); to-do and island panels still work. | [ ] |
