# M5 Computer Use: manual checklist

Covers FR-CU-01 to 15. Keep a hand near Esc.

| # | Step | Expected | Pass |
|---|---|---|---|
| 1 | Home > Run a task: "Open Notepad and type hello world". | First task this session: a confirmation card with the goal and a warning appears on the island. No has focus; Esc means No. | [ ] |
| 2 | Click Yes. | The banner "Wisp is controlling your PC. Esc x3 to stop" shows. A ring flashes at each click point and the island shows each step's intent. Notepad opens with "hello world" in under 12 steps. | [ ] |
| 3 | Run a second task in the same session. | No first-task card this time. | [ ] |
| 4 | Start a long task, then press Esc three times quickly. | Everything stops within 1 s. No keys or mouse buttons are stuck (type in Notepad, click around). | [ ] |
| 5 | Start a task, then press a key or click yourself. | The task pauses; the island offers Resume and Stop. Both work. | [ ] |
| 6 | Task: "go to a login page and type a password" (any site). | Wisp asks for confirmation (model safety decision or guard list) before continuing. | [ ] |
| 7 | Open a window titled with "bank" (e.g. a browser tab about a bank) and give a task there. | Wisp pauses for confirmation because of the guard list, whatever the model says. | [ ] |
| 8 | Leave a confirmation card unanswered for 5 minutes. | It counts as No and the task stops. | [ ] |
| 9 | Run a task with an admin window (e.g. Task Manager) in front. | Wisp stops and explains that Windows blocks it. | [ ] |
| 10 | Settings > Privacy > Debug screenshots on; run a task. | Screenshots appear in `%APPDATA%\Wisp\debug`; they are deleted after 24 h. Turn it off. | [ ] |
| 11 | History. | The task shows each step: time, intent, action and arguments, safety decision, your answer. | [ ] |
| 12 | Settings > Safety: set Max steps to 3 and run a long task. | It stops after 3 steps with a clear message. Set it back to 40. | [ ] |
| 13 | Command mode: "open calculator and compute 12 times 7 by clicking". | The command model calls run_computer_task and the task runs. | [ ] |
| 14 | Settings > Safety: choose your second monitor for Computer Use. | Tasks capture and click on that monitor; rings appear on it. | [ ] |
