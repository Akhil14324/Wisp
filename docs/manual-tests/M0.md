# M0 Skeleton and setup: manual checklist

Covers FR-SET-01 to 09 and NFR-10 to 12. Run on a Windows 11 user profile. Mark each box.

| # | Step | Expected | Pass |
|---|---|---|---|
| 1 | Run the NSIS installer from CI (or `npm run tauri build`). | Installs without an admin (UAC) prompt, into `%LOCALAPPDATA%`. | [ ] |
| 2 | Launch Wisp for the first time. | Tray icon appears. The main window opens on the setup wizard. The island pill shows at top-centre. | [ ] |
| 3 | Step 1: try Continue without ticking "I understand". | Continue is disabled. The text says audio, screenshots and clipboard text go to Google and may be used on the free tier. | [ ] |
| 4 | Tick it and continue. Step 2: click Open Google AI Studio. | `https://aistudio.google.com/apikey` opens in your default browser. Wisp does nothing else on that page. | [ ] |
| 5 | Step 3: paste a wrong key (e.g. change one character) and Validate. | Error with an HTTP status and "Gemini rejected the key…". | [ ] |
| 6 | Turn off Wi-Fi and Validate. | "No network connection to Gemini." | [ ] |
| 7 | Turn Wi-Fi on, paste the real key, Validate. | "Key works. N models are available." The wizard moves to step 4. | [ ] |
| 8 | Step 4: watch the meter while talking; press Test and say a sentence. | The meter moves; after 3 s the recording plays back. | [ ] |
| 9 | Windows Settings > Privacy > Microphone: turn off "Let desktop apps access your microphone"; press Test. | Error message and an "Open microphone privacy settings" button that opens `ms-settings:privacy-microphone`. Turn access back on. | [ ] |
| 10 | Press Finish. Time from first launch to here. | Under 3 minutes. | [ ] |
| 11 | Open Credential Manager > Windows Credentials. | An entry `Wisp/GeminiApiKey` exists. | [ ] |
| 12 | Search for the key text in `%APPDATA%\Wisp\` and `%LOCALAPPDATA%\Wisp\logs\` (e.g. `findstr /s /c:"AIza" *`). | No matches. | [ ] |
| 13 | Settings > About: the key shows as `••••` plus the last 4 characters. Try Replace, then Delete. | Both work; after Delete, Home says "No key". Re-add the key. | [ ] |
| 14 | Settings > Models. | One dropdown per role filled from your model list; any default missing from the list shows "not available". | [ ] |
| 15 | Launch Wisp again from the Start menu while it is running. | No second instance; the existing main window comes to the front. | [ ] |
| 16 | Close the main window with X. | It hides; Wisp keeps running in the tray. Tray > Open shows it again. | [ ] |
| 17 | Tray > Pause hotkeys. | The menu item is checked; chords do nothing until you uncheck it. | [ ] |
| 18 | Sign out and back in. | Wisp starts automatically (autostart is on by default). Turn it off in Settings > General and check it no longer starts. | [ ] |
| 19 | Home shows "requests today" and "rate limited" counters. | They count up as you use Wisp. No prompts or audio appear anywhere in the database (open `wisp.db` with any SQLite viewer and check `usage_counters`). | [ ] |
| 20 | Tray > Quit. | The island, tray icon and process all go away. | [ ] |
