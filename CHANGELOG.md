# Changelog

## 0.1.0 (unreleased)

First build of milestones M0 to M7 from the SRS.

- Setup wizard, key storage in Credential Manager, models page, tray, autostart, single instance (M0)
- Low-level keyboard hook with chord state machine, dictation with clipboard-safe insertion (M1)
- Command mode with 15 local tools, app index, search engines, typed fallback, Loadouts (M2)
- Circle to Ask with overlay drawing, crops, answer card and follow-ups (M3)
- Scheduler and routines with missed-run, lock and queue handling (M4)
- Computer Use agent with safety decisions, guard list, emergency stop, takeover pause and audit log (M5)
- To-do list with reminders, island panels, four customization slots with import/export (M6)
- Hardening: database recovery, delete all data, diagnostics, sleep/resume, panic cleanup (M7)

Not included: M8 Live mode (optional).
